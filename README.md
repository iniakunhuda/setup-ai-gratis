## Rekomendasi Cepat

- **Editor utama VSCode, tanpa ribet** → [Gemini](gemini/README.md) atau [Copilot Free](copilot/README.md)
- **Mahasiswa/guru/maintainer OSS** → [Copilot Student](copilot-student-pack/README.md) (unlimited)
- **Agentic CLI di terminal** → [OpenCode](opencode/README.md) atau [Qwen Code](qwen-code/README.md)
- **IDE agentic terpisah** → [Antigravity](antigravity/README.md) (free tier paling royal)
- **Generate UI full-stack** → [v0](v0/README.md)

## Catatan Umum

- Semua yang terdaftar **tidak butuh kartu kredit** kecuali disebutkan lain.
- Free tier bisa berubah sewaktu-waktu — cek selalu halaman pricing resmi di masing-masing panduan.
- Panduan dibuat per **September 2026**.
