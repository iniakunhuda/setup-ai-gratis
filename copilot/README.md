# Setup GitHub Copilot — AI Gratis untuk VSCode

GitHub Copilot punya plan **Copilot Free** — cukup akun GitHub (gratis), tanpa kartu kredit:

- **2.000 code completions/bulan**
- Chat terbatas (50 chat requests/bulan) + akses terbatas ke fitur lain (agent mode, pemilihan model)
- **Gratis 100%** untuk **siswa/mahasiswa (GitHub Student Pack), guru, dan maintainer open-source** — completion jadi unlimited

## Prasyarat

- Akun [GitHub](https://github.com) (gratis)
- [VSCode](https://code.visualstudio.com) versi terbaru

## Cara Setup di VSCode

1. Buka VSCode → klik ikon **Copilot** di title bar (atau **Extensions** `Ctrl+Shift+X` / `Cmd+Shift+X` → cari **"GitHub Copilot"** → **Install**).
2. Klik **Sign in to use Copilot** / ikon akun di pojok kiri bawah → **Sign in with GitHub to use Copilot**.
3. Login akun GitHub di browser.
4. Saat ditanya plan, pilih **Copilot Free**.
5. Extension pendamping (Copilot Chat) terinstall otomatis saat setup pertama.

Selesai — suggestions muncul inline saat mengetik (terima dengan `Tab`), dan chat + agent mode ada di panel samping (`Ctrl+Shift+I` / `Cmd+Shift+I`).

## Tips

- **Status kuota**: klik ikon Copilot di status bar untuk lihat sisa kuota bulan ini.
- **Model**: di panel chat bisa pilih model (mode auto di plan gratis).
- **Mahasiswa/maintainer**: daftar [GitHub Education](https://education.github.com) atau cek [CoproFree untuk maintainer](https://github.blog/news-insights/company-news/github-copilot-free-for-maintainers-of-popular-open-source-projects/) untuk akses gratis penuh.

## Catatan

- Kuota habis bulan ini = fitur berbayar berhenti sampai bulan depan, tidak auto-charge (plan free tidak punya billing).
- Butuh unlimited & model terbaik? Upgrade ke **Copilot Pro** (ada free trial 30 hari).
- Akun di organisasi: admin bisa menonaktifkan fitur chat/agent mode.
