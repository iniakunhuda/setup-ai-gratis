# Setup Devin Desktop (ex-Windsurf) — AI IDE Gratis dari Cognition

> **Windsurf sekarang jadi Devin.** Setelah diakuisisi Cognition, Windsurf IDE berevolusi jadi **[Devin Desktop](https://devin.ai/desktop)** — pengguna Windsurf lama dapat update over-the-air; plan, extension, dan setting ikut terbawa, cuma ganti branding.

Devin Desktop = IDE bawaan + **Agent Command Center** untuk mengelola banyak coding agent (lokal & cloud) dari satu tempat.

**Plan Free:**

- **Unlimited access ke SWE-2** — model coding paling canggih mereka
- Unlimited inline edits & Tab completions
- Agent sessions dengan light quota (refresh harian/mingguan)
- Hingga 10 concurrent sessions

## Prasyarat

- macOS (cek halaman download untuk platform lain)
- Akun untuk login (Google/GitHub/email)

## Cara Setup

### 1. Download & Install

1. Buka [devin.ai/desktop](https://devin.ai/desktop).
2. Klik **Download for MacOS** → install seperti aplikasi biasa.

### 2. Login

1. Buka aplikasi → sign in dengan akun kamu.
2. Otomatis masuk plan **Free** — tanpa kartu kredit.

### 3. Mulai Pakai

- **IDE bawaan** — syntax highlighting, autocomplete, debugging; basisnya Windsurf (fork VS Code) jadi terasa familiar.
- **Supercomplete** — prediksi edit berikutnya.
- **Agent Command Center** — delegate tugas ke agent, pantau statusnya (Running / Waiting for review / Waiting for CI / Done) di tampilan kanban.
- **Spaces** — shared context + git worktree untuk multi-agent.
- **MCP & extensions** — dukungan Slack, Linear, Notion, Figma, Sentry, dst; plus ESLint, Prettier, rust-analyzer, gopls, Pyright.
- **ACP (Agent Client Protocol)** — bisa sambungkan model/agent pihak ketiga.

## Alternatif: Windsurf for JetBrains

Punya IntelliJ IDEA / PyCharm / WebStorm? Plugin **Windsurf** tetap tersedia terpisah untuk JetBrains.

## Catatan

- Kuota agent free tier refresh **harian & mingguan** (bukan bulanan) — penggunaan berat cepat kena limit.
- Model premium/frontier tertentu dan fitur cloud (Devin Cloud, DeepWiki, API) butuh plan berbayar (Pro $20/bln, Max $200/bln).
- Editor AI gratis dengan fitur serupa: lihat [Cursor](../cursor/README.md) dan [Kiro](../kiro/README.md).
