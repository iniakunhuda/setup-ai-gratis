# Setup Copilot Student — AI Gratis untuk Mahasiswa di VSCode

Verifikasi sebagai **mahasiswa di GitHub Education** → dapat akses **Copilot Student gratis**, setara fitur Copilot Pro:

- **Unlimited code completions** (bandingkan Copilot Free: cuma 2.000/bulan)
- Chat + agent mode dengan allowance AI credits
- Bonus: **GitHub Student Developer Pack** — banyak tools & cloud credit gratis lainnya (JetBrains, DigitalOcean, domain, dll)

## Prasyarat

- Akun GitHub
- Status mahasiswa aktif (punya NIM/email kampus, kartu mahasiswa, atau bukti belajar lainnya)
- Usia minimal 13 tahun

## 1. Daftar & Verifikasi GitHub Education

1. Login ke GitHub, buka [github.com/settings/education/benefits](https://github.com/settings/education/benefits).
2. Klik **Start an application**.
3. Isi data: nama sekolah/kampus, alur cerita bagaimana kamu menggunakan GitHub untuk belajar.
4. Upload **bukti status mahasiswa** (kartu mahasiswa, surat keterangan aktif, atau foto dokumen yang jelas). Lebih mudah disetujui kalau kamu juga punya **email kampus** yang bisa diverifikasi.
5. Izinkan akses lokasi perangkat saat verifikasi (diminta GitHub untuk mencocokkan lokasi kampus).
6. Tunggu peninjauan — biasanya beberapa hari sampai ~1 minggu.

## 2. Aktifkan Copilot Student

Setelah verifikasi **disetujui**:

1. Buka lagi [github.com/settings/education/benefits](https://github.com/settings/education/benefits).
2. Di bagian **"Free GitHub developer resources for students and teachers"**, klik **Learn more**.
3. Ikuti prompt untuk **mengaktifkan Copilot Student** dan atur Copilot use policies sesuai kebutuhan.

> **Kalau masih muncul Copilot Free / halaman bayar:** persetujuan verifikasi dan aktivasi Copilot itu dua langkah berbeda — benefit bisa makan waktu beberapa hari. Jangan selesaikan pembayaran! Cek [github.com/github-copilot/free_signup](https://github.com/github-copilot/free_signup), kalau cuma muncul opsi berbayar, tunggu beberapa hari lalu coba lagi.

## 3. Setup di VSCode

Sama seperti Copilot biasa:

1. Buka VSCode → **Extensions** (`Ctrl+Shift+X` / `Cmd+Shift+X`) → cari **"GitHub Copilot"** → **Install**.
2. Klik **Sign in with GitHub to use Copilot** → login akun GitHub kamu.
3. Extension Copilot Chat terinstall otomatis.

Selesai — completion unlimited dan chat aktif. Status plan bisa dicek di ikon Copilot di status bar.

## Catatan

- GitHub **mengevaluasi ulang eligibilitas tiap bulan** — jaga status mahasiswa & data verifikasi tetap valid.
- Plan gratis student **tidak bisa di-cancel** sendiri; hilang otomatis kalau tidak lolos re-evaluasi.
- Guru (verified teacher) dan maintainer open-source populer juga bisa dapat **Copilot Pro gratis** lewat jalur yang sama.
